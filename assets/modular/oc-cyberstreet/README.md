# CyberStreet OC · original modular starter pack

This is a first **real, editable vector asset pack** for the BotImagen character-assembly pipeline. It is not an imported Honkai model or a finished high-fidelity character.

## Contents

- `base-body.svg`: neutral front-view body base
- `hair-midnight-cyan.svg`: detachable midnight/cyan anime hair
- `top-neon-jacket.svg`: detachable cropped jacket
- `skirt-tech-pleated.svg`: detachable techwear skirt
- `manifest.json`: canvas, anchors, layer order, roles, and attribution metadata

All SVGs share a 512 × 768 transparent canvas. The initial anchors are estimates, not validated compositor coordinates. The pack must be visually checked in the actual React/Python renderer before its state is promoted from `component_candidate` to `component_validated`.
