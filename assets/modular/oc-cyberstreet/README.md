# CyberStreet original modular starter pack

This pack contains 15 original, editable SVG components for a neutral 512×768 front-facing anime character. The six initial options retain the cyber-street style; nine alternatives introduce an athletic body, two alternate face expressions, two hair styles, two upper garments and two lower garments.

## Per-slot choices

- Body: neutral base or athletic variant.
- Face: cyan-eyed face, amber eyes or a wink expression.
- Hair: midnight cyan, rose twin tails or silver bob.
- Upper garment: neon jacket, varsity jacket or gothic blouse.
- Lower garment: tech pleated skirt, magenta short skirt or cargo pants.
- Footwear: neon sneakers (the one available choice in this starter set).

Each layer declares its slot and default status. Only the first choice in each slot is active by default; the SVG composer and PNG library switch alternatives instead of stacking multiple bodies, faces, hairstyles or garments. The PNG importer creates an independent 512×768 RGBA PNG, calculates SHA-256 and preserves source file, source URL and licence declaration. An imported candidate still requires explicit anchor confirmation before modular composition.

All SVG components in this directory were authored for this repository by BotImagen Studio. The source licence identifier is `LicenseRef-BotImagen-Original-Assets`; it describes these repository-owned components, not third-party content. No external artwork, game-extracted resource or paid generation is included.

These 15 components expand the starter pack but do not make the universal catalogue complete. Additional original/licensed assets and human review of each fit/anchor remain required before the full product can be declared ready.
