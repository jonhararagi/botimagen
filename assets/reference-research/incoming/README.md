# Incoming reference assets

Colocar aquí únicamente archivos descargados cuya redistribución esté autorizada por la licencia concreta.

Antes de añadir un archivo:
- guardar la URL de origen y autor;
- verificar la licencia del archivo y del paquete;
- conservar el aviso de copyright/licencia si corresponde;
- registrar fecha de consulta y SHA-256 en ../manifest.json;
- evitar checkpoints/LoRA pesados: guardar enlaces y metadatos en vez de los pesos.

Esta carpeta no contiene assets todavía. No copiar imágenes de galerías de PixAI, Civitai o SeaArt sin permiso expreso.
