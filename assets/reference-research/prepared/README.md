# Prepared character references

Destino para copias de trabajo aprobadas y listas para probar en el compositor de BotImagen.

Flujo previsto:
1. Importar un original aprobado desde ../incoming/.
2. Mantener el original sin modificar.
3. Crear una copia de trabajo PNG con transparencia y marca de agua solo si se necesita identificar una base de prueba.
4. Preparar y revisar regiones separadas: cuerpo, cabeza, ojos, cabello, ropa y accesorios.
5. Registrar en ../manifest.json el origen, licencia, hash del original y transformaciones.

La separación automática actual es raster/geométrica y puede necesitar corrección manual. No afirmar que una región sea «ojos» o «ropa» hasta revisarla visualmente.
